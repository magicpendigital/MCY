# Owner local preview 5.3 — hướng dẫn chuẩn bị, chưa khởi chạy

**Trạng thái:** `BLOCKED_OWNER_START_UNTIL_ROOT_GO`. Chỉ dùng candidate cô lập `.vercel/ux-step5-3-20261018-v1` và CLI đã review `server/contentReview/startLocalReview.mjs`; mode được cố định lúc khởi động là `owner_local_preview`, port dự kiến `4260`, loopback `127.0.0.1`. Trang sau bootstrap là `/?workspace=unit-review&mode=web`. Đây là mặt web local, không phải native/simulator hay bản phát hành.

Sau root GO và sau khi các pin source/artifact, Node control, browser fixture, QC độc lập đều khớp, chạy CLI trong child process riêng với working directory là candidate, `node server/contentReview/startLocalReview.mjs --mode owner_local_preview --port 4260`. Môi trường child chỉ cho `SystemRoot`, `WINDIR`, `PATH`, `TEMP`, `TMP`, `USERPROFILE`; không chuyển `NODE_OPTIONS`, provider key, `.env` hoặc credential. Trên Windows, launcher cần `ProcessStartInfo` với `UseShellExecute=false`, `CreateNoWindow=true`, `WindowStyle=Hidden`, `Environment.Clear()` rồi bổ sung đúng sáu biến OS trên; chuyển stdout/stderr vào file receipt riêng. Không ghi capability value. Ghi PID, lệnh, giờ bắt đầu, source/artifact pin và đường dẫn capability **chỉ là file path** trước các health check.

CLI tạo capability dùng một lần trong `.vercel/local-review-private/` ngoài Vite/candidate; terminal/receipt chỉ được ghi đường dẫn, PID và origin. Root dùng CUA đọc private file vào bộ nhớ rồi nhập giá trị vào form tại `http://127.0.0.1:4260/__mcy_review/v1/bootstrap`. Không đặt giá trị vào URL, query, referrer, log, clipboard công khai, `localStorage` hoặc test artifact. Bootstrap POST đòi đúng Host/Origin của local process và form content type, xóa file capability sau khi dùng và đặt cookie HttpOnly SameSite Strict của lease tạm. Plain URL chỉ mở được workspace khi lease hiện hành hợp lệ. Capability chưa dùng hết hạn tối đa năm phút; muốn cấp lại phải dừng đúng process rồi khởi động một process mới, không tái dùng file cũ.

Owner mode chỉ xem 14 draft unit được chọn tường minh và asset đã pin, ghi note tạm trong bộ nhớ nếu lease cho phép; endpoint edit/review bị từ chối. 25 media slot `identity_blocked` phải hiện trạng thái thiếu, không thay bằng ảnh khác. Mỗi read/asset kiểm lease/epoch/source/version, no-store và static allowlist; nếu upstream canonical hoặc build artifact lệch pin thì fail closed. Review thực tế, danh tính Teacher/Reviewer, quyền/rights, tính an toàn chuyên môn, public learner catalog và release vẫn `BLOCKED`/chưa được chứng nhận. Không coi Owner preview là quyết định nhân sự hoặc duyệt sức khỏe.

Trước khi trao URL cho Root, xác nhận riêng: process PID thuộc đúng CLI candidate, `GET /__mcy_review/v1/session` chưa bootstrap trả `authenticated:false`, CSP/no-store, source pin 9+71 và artifact static pin khớp; không dùng truy cập `/@fs`, source/test hoặc endpoint mutation làm health check. Khi kết thúc, dừng **chỉ PID đã ghi và xác nhận thuộc CLI này**, xác nhận port 4260 hết phục vụ, rồi xác minh đường dẫn private dir nằm trong `.vercel/local-review-private/` trước khi dọn file còn sót. Không kill Edge/process khác, không xóa thư mục bằng path suy đoán. Nếu process chết hoặc capability hết hạn, ghi failed receipt và dùng launch mới sau root quyết định; không gọi UI/Owner PASS dựa trên server startup.
