# 6.1 — Mẫu kết quả và quyết định, chưa có dữ liệu

**TEMPLATE EMPTY — chưa chạy pilot, không điền số 0 như kết quả.** Chỉ điền sau khi được phép chạy theo [readiness](PILOT-READINESS.vi.md), [protocol gốc](../ux-implementation-2026-10-14/content/pilot-test-protocol.md) và [moderator packet](MODERATOR-PACKET.vi.md). Không nhập định danh/liên hệ/tài khoản, tình trạng sức khỏe, ảnh/audio/video hoặc quyết định chuyên môn tự tạo.

| Mã nghiên cứu không định danh | Vòng | Lượt mới/quay lại | Moderator/người ghi theo phân công | Ngày | Artifact ID/revision/locale/SHA và asset hashes hoặc evidence ref | Task được phép |

|---|---|---|---|---|---|
| | | | | | |

## Quan sát, diễn giải và trợ giúp

Dùng mã task từ [ma trận](ROUTE-TASK-MATRIX.vi.md). Thời gian là tương đối với task; ghi đơn vị. Không có phản hồi là thiếu dữ liệu/bỏ qua, không là hiểu đúng hoặc cải thiện. Không ghi lại nội dung nhạy cảm trong phần quan sát hay diễn giải.

| Mã nghiên cứu/vòng/task | Artifact/vị trí | Thời gian chọn/đơn vị | Quan sát không định danh | Trợ giúp đã dùng | Hiểu sai hoặc trạng thái bỏ qua/dừng | Diễn giải của nhóm, tách khỏi quan sát | Cần xác minh |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

| Task/chỉ số định tính | Số trường hợp | Mẫu số hợp lệ | Thiếu dữ liệu/bỏ qua | Trước hay sau trợ giúp | Giới hạn/phiên bản |
|---|---|---|---|---|---|
| | | | | | |

| Mã nghiên cứu/vòng | Lý do muốn/không muốn quay lại do người đọc nêu, không định danh | Không trả lời/giới hạn |
|---|---|---|
| | | |

## Bảng quyết định sau tổng hợp

Không dùng bảng này làm approval record. Người có trách nhiệm phải cung cấp quyết định thật gắn exact bytes/scope ở hồ sơ review sẵn có. Nhóm phân loại vấn đề về hiểu sai hành động/loại nội dung, thiếu thông tin, trợ giúp hoặc cách trình bày; chưa đủ evidence thì giữ pending.

| Finding/evidence ref | Mức ưu tiên và lý do | Phần bị ảnh hưởng | Người chịu trách nhiệm theo phân công | Đề xuất xử lý | Quyết định thật/ngày/evidence ref | Phiên bản cần review lại | Điều kiện vòng kế/giữ BLOCKED |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

| Nội dung/phiên bản nào được xét cho vòng kế | Evidence matching và scope | Người quyết định | Ngày | Kết luận/giới hạn |
|---|---|---|---|---|
| | | | | |

## Quản lý ghi chú và báo cáo

| Custodian/nơi lưu được chọn | Ai được xem | Ngày xóa/retention | Cách nhận yêu cầu rút lại và giới hạn sau tổng hợp | Xử lý dòng vô tình có thông tin nhạy cảm | Xác nhận xử lý theo phương án |
|---|---|---|---|---|---|
| | | | | | |

Báo cáo chỉ mô tả hiểu/sử dụng tài liệu và giờ công; không suy hiệu quả sức khỏe, độ an toàn lâm sàng, sự phù hợp vận động, quyết định khóa học hay AI runtime từ completion, lời khen hoặc im lặng. Cỡ mẫu nhỏ không đại diện dân số. Không xuất bản/chia sẻ notes hoặc bản nháp theo mẫu này; access và quyền phải được chốt riêng trước thực hiện.
