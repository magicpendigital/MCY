## Implementation packet kế tiếp, không chỉ kế hoạch giấy

1. Giữ common web/APK artifact đang chuẩn bị; hoàn tất package QC, bounded critical regression (`ux-save-feedback`, `learner-device-acceptance`, `auth-callback`) và root guest smoke trên đúng web bytes bằng CSP guard. Reuse accepted layout evidence chỉ khi source/environment phù hợp; không chạy lại toàn lịch sử142checks theo mặc định.
2. Chuẩn bị diff thật cho private review delivery: client transport adapter + API contract + authenticated Edge handler + private object mapping/assignment storage nếu cần + fixtures/live matrix + rollout/disable. File names/schema chốt trong intake con R3 sau bounded current-state read; đây là hành vi mới, chưa được common-source GO cho sửa. Native relative `/__mcy_review/v1` phải được thay bằng transport được cấu hình đúng, không dùng desktop Node reader như backend thật.
3. Chuẩn bị exact role/assignment/content-admission operations từ actual target/ledger/actor evidence. Apply selective compatible server changes trước web/native consumer; giữ learner writer/helper/RLS/old-client fail-closed behavior. Không dùng `db push`, redeploy hàng loạt hoặc thay config không liên quan.
4. Bind human decisions với toàn pool đã chọn:38clips/3courses,14unit versions/assets, intro4assets và114metadata theo đúng purpose/stage, không yêu cầu Owner chọn lại chỉ14bài. Review results đi qua audited server boundary. Chỉ tạo published PracticeSession khi có complete approved session facts; metadata/lineage không làm tăng session count. “All prepared” không ép identity-blocked/unreviewed media vào public.
5. Freeze manifests riêng web/native/server/data operations; independent R3 + root direct check, exact human release decision theo runbook, rồi execute staged access/smoke/observation. Nếu practice gate thiếu, báo chính xác phần còn thiếu và tiếp tục hoàn thiện phần có thể làm; không đổi scope thành mock edition để gọi complete.

## Effects/caps cần bind trước live execution

Packet phải ghi chính xác từng existing actor UID label, capability/global-role/profile/assignment nào cần thêm hay đã tồn tại, thời hạn/revoke, từng unit/session/asset hash, bucket/privateobject count, draft/review/publish transitions, consent/check-in/observation/Auth-metadata caps, email trigger count, artifact/API targets, monitoring window/threshold và recovery. Hiện các caps mới **chưa xác định**, không mặc định lấy budget13–14/10. Provisioning hai lượt dependencies chỉ là local build tooling; không data/role allowance.

Learner roster/moderator/data custodian/support owner, nơi giữ notes, access/retention/withdraw handling và exact review/rights facts vẫn phải nhận để vận hành thật. Không lấy contacts riêng để lấp facts. Có thể xác minh tài khoản được Owner nêu bằng read-only evidence nhưng không tự cấp quyền, gửi mail hoặc collect health data.

Stop khi target/protection/actor mismatch, unknown/extra effect, draft/content/hash change, thiếu role/rights/session completeness, leaked content hoặc native session bất định. Recovery ưu tiên disable new capability/compatible forward fix; giữ cloud history, extra B row, old approvals/receipts/APKs và root dirty. Không hứa DB rollback, APK downgrade hoặc xoá dữ liệu để đạt cap. Full-real rollout vẫn pending, common artifacts tiếp tục được hoàn thiện.
