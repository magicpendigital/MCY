# Một chút Yoga MVP prototype

Interactive mobile prototype built from the selected refined visual direction.

## Core learner flow

Welcome → Daily Body Check-in → Today’s Practice → Practice → Post-practice Reflection → Progress.

## Added MVP concepts

- Teacher feedback cards tied to a course and named teacher.
- AI summary cards tied to user-provided check-ins, reflections, and practice activity.
- A clear benefits screen for the human-led course model and the AI subscription model.
- Teacher workspace demo: write a note, see the system-generated card preview, and send it.

## Run locally

```bash
npm ci
npm run dev
```

See `design-qa.md` for browser verification notes.
